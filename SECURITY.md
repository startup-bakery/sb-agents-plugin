# Security

Do not include passwords, access tokens, cookies, tenant data, contact records, or private job results in GitHub issues.

Report suspected vulnerabilities privately through this repository's GitHub Security advisories when private reporting is available. Otherwise, contact your existing Startup Bakery account administrator and ask for a private reporting channel before sharing sensitive details.

The plugin uses OAuth with the Startup Bakery gateway. Account access, tenant permissions, quotas, and operation confirmations are enforced by the gateway. Installing or editing the plugin does not grant additional permissions.
